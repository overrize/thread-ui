# 螺丝刀 AMOLED UI 实现路线

面板：0.95" AMOLED Bar，120×240，SH8501A，4 线 SPI
主控：ESP32-S3
目标：主界面螺纹动画 60fps

---

## 1. 硬件约束（已从数据手册确认）

| 项 | 结论 | 影响 |
|---|---|---|
| 垂直滚动 | **不支持**。命令表里 33h / 37h 不存在 | 不能用硬件滚动做动画，必须走像素传输 |
| SPI 写时钟 | twc4 min 20ns → **上限 50MHz** | 决定帧预算 |
| SPI 读时钟 | trc4 min 100ns → **上限 10MHz** | 运行时不要读寄存器 |
| TE 撕裂同步 | IC 有 TE 输出（TEON 35h / TESCAN 44h），**模块未引出** | 满屏动画会撕裂，改板时必须引出 |
| QSPI | IC 支持（IM[2:0]=010，SDIO_0~3），**当前模块只有单 SDA** | 想要 4 倍带宽需换模块 |
| 局部显示 | PTLON(12h) + PTLAR(30h) + PTLAC(31h) | 省电用，不能滚动 |
| 亮度 / AOD | WRDISBV(51h)、HBMCTL(66h)、AODON(49h) + AOD_WRDISBV(4Ah) | 待机低功耗、防烧屏 |

## 2. 帧预算

一帧 = 16.7ms（60fps）

| 像素格式 | 每帧数据 | @50MHz | 总线占用 |
|---|---|---|---|
| RGB565 全屏 | 57.6 KB | 9.2 ms | 55% |
| RGB565 仅螺纹区（120×226） | 54.2 KB | 8.7 ms | 52% |
| **1-1-1 调色板 4bpp** | **14.4 KB** | **2.3 ms** | **14%** |
| 数字脏矩形（80×36） | 5.8 KB | 0.9 ms | 按需，5~10Hz 足够 |

调色板模式：COLMOD(3Ah) 选 1-1-1，颜色由 COLSET0~15（70h~7Fh）+ COLOPT(80h) 定义，
每字节两像素。**换模式只重写 COLSET 寄存器，几十字节，零像素传输。**

## 3. 渲染方案：贴图 + 行拷贝

螺旋线在 y 方向严格周期：t 增加 2π 时 x 回到原值，y 前进一个牙距。
所以整屏只是**一张一个牙距高的贴图在纵向重复**。

- 贴图尺寸：17 × 120
- RGB565 存 4 KB；1-1-1 调色板存 1 KB（三模式共 3 KB）
- 每帧：对每行 y 拷贝贴图第 `(y + offset) % 17` 行，240 次 memcpy × 240 字节

**分工**
- 贴图（PC 端生成 → C 数组）：只有螺纹。抗锯齿、牙谷遮蔽、圆柱光照、抖动全部预先烘进去
- 手写代码：状态条、数字、进度条。动态内容，形状简单，代码画更灵活

**生成贴图的坑**：别从整屏截一段，round cap 会被切断、接缝对不上。
正确做法是渲染连续 5 个周期，**取中间那一个**。

**滚动步进** = 牙距 × rpm / 3600 px/帧
- 450rpm → 2.1 px/帧；900rpm → 4.25 px/帧
- **超过牙距一半（8.5px/帧 ≈ 1800rpm）触发 Nyquist，螺纹看起来倒转**
- 步进只能取整，用小数累加器攒够整数再走

## 4. 视觉规范

### 螺纹几何
| 参数 | 值 | 说明 |
|---|---|---|
| 牙距 pitch | 17 px | 贴图高度，动画周期 |
| 线宽 wire | 14 px | **wire/pitch ≈ 0.85 是"螺纹"，低于 0.5 会变成"弹簧"** |
| 振幅 amp | 46 px | 等径，侧面轮廓是长方形 |
| 透视深度 depth | 4.5 px | 越小越像实心杆 |
| 描边 | wire + 2，纯黑 #0A0C14 | |

### 光照（从一个基色推导全部图层）
| 图层 | 系数 |
|---|---|
| 牙面色阶（565 路线，6 档） | .40 / .60 / .84 / 牙峰向白 +16% / .84 / .54 |
| 牙面色阶（优化 / 调色板，4 档） | .42 / .72 / 牙峰向白 +20% / .58 |
| 背面圈 | ×0.34 |
| 牙谷遮蔽 | ×0.14~0.20，宽 0.55~0.62×wire，偏移 (0.6, 0.30×wire) |
| 右缘冷反光 | 4px 宽 #CFF0FF @0.85，screen 混合 |
| 抖动 | 4×4 bayer，13%（**仅 565 路线，4bpp 下会变噪点**） |

565 路线所有颜色**预先对齐到格点**：`(r&0xF8)|(r>>5)`，避免量化漂移。

### 三个模式
| 模式 | 基色 | 扭矩 | 转速 | 动画 |
|---|---|---|---|---|
| 精密 | #2FA8FF | 0.35 N·m | 200 rpm | 连续旋转 |
| 标准 | #FF8A2B | 1.20 N·m | 450 rpm | 连续旋转 |
| 棘轮 | #3ED66A | 2.40 N·m | — | **一格一牙的咬合，0.18s 一次** |

切换时：颜色 0.7s 缓动；连续模式给转速冲量，棘轮模式改为六下减速咬合。
每个模式记住自己的扭矩设定。

### 排版
- **中文最小 12px**。8px 汉字在 120px 宽屏上只有 5×5 有效像素，糊成一团
- 扭矩数字 30~32px，等宽粗体，收紧字距
- 次要信息（实时扭矩、计数、操作提示）下放到菜单，不占主界面

### 主界面分层
```
状态条 14px   模式徽标 | 转速 | 电量（不放时钟）
螺纹     226px  满屏，无边距
扭矩数字 44px   渐变压条叠加，只有一个数
```
底部提示条已去掉——语法一周成肌肉记忆，之后每天白占 6% 面积。

## 5. 交互语法（横置滚轮 + 按键，单输入）

| 场景 | 滚动 | 短按 | 双击 | 长按 |
|---|---|---|---|---|
| 主界面 | 调扭矩 | 进菜单 | 换模式 | 锁屏 |
| 菜单 | 移光标 | 进入/编辑 | — | 返回上级 |
| 编辑 | 改数值 | 保存 | — | **放弃改动**（回滚进入前的值） |
| 确认条 | 切换选项 | 执行 | — | 取消 |

原则：**短按永远前进，长按永远后退**，不能有例外。
防误触：一旦开始滚动就取消长按计时；运行中屏蔽短按；危险操作默认停在"取消"。
菜单只做到三级。

## 6. 里程碑

**M0 硬件确认**
- 确认模块 TE 是否可引出；不能就评估撕裂可接受度
- 确认是否换 QSPI 模块（决定后面所有带宽余量）
- 跑纯色块，实测 RGB565 色阶带出在哪几档，倒推抖动强度

**M1 打通显示**
- esp_lcd + SPI DMA，50MHz 写，10MHz 读做 ID 校验
- 参考 `esp_lcd_sh8601` 组件（同厂 SH8601，命令集接近，需按 SH8501A 手册核对）
- 显示一张静态贴图，确认颜色和方向

**M2 动画跑起来**
- 贴图导出 → 行拷贝 → 局部窗口刷新
- GPIO 翻转 + 逻辑分析仪测真实帧率，渲染和推屏分开计时
- 不到 60fps 就切 1-1-1 调色板路线

**M3 完整主界面**
- 数字脏矩形、三模式、棘轮咬合
- 模式换色走 COLSET 寄存器

**M4 菜单与输入**
- 滚轮编码 + 短按/双击/长按判定（去抖、长按阈值 500ms）
- 状态机移植，编辑态备份/回滚

**M5 AMOLED 收尾**
- 防烧屏：定期 1~2px 整体偏移、息屏超时、WRDISBV 降亮度
- AOD 待机屏：只留扭矩数字
- 功耗实测：黑底不耗电，满屏橙螺纹是大头，考虑只在运行时全亮

## 7. 风险清单

| 风险 | 触发条件 | 对策 |
|---|---|---|
| 画面撕裂 | 无 TE，满屏动画 | 改板引出 TE；或缩小刷新窗口 |
| 烧屏 | 状态条/数字长期固定 | 像素偏移 + 息屏 + 降亮度 |
| 动画倒转 | 显示转速 > ~1800rpm | 限制映射，或换模糊贴图 |
| 贴图接缝 | 从整屏截取 | 渲染多周期取中间 |
| 带宽不够 | 565 全屏 + 其他外设抢总线 | 切调色板模式或 QSPI |
| 色阶断裂 | 4bpp 下用抖动 | 调色板路线放弃抖动，靠 8 个精选色 |
