# SPEC —— 螺丝刀机身 AMOLED 主界面

版本 1.4.5 · 唯一事实来源。原型 `prototype/screwdriver-ui.html` 是本规格的可执行参考，两者冲突时以本文为准并修正原型。

> 本包说明：文中提到的 FIRMWARE_GUIDE / gen_luts 指设计包（QuantDriver-Device-UI_v1.4.5）。本包的固件实现以 `docs/IMPLEMENTATION.md` 和 `firmware/` 为准。

---

## 1. 一句话

屏幕是机壳上开的一扇**观察窗**，紧贴着里面正在转动的铜芯电枢。转子铺满窗口，两侧向后弯走、变暗、失焦。扭矩与转速像贴在玻璃上的仪表标注，一条与转子同斜的**弧面槽格**作为能量条，按旋向填充。

## 2. 面板与版式

| 项 | 值 |
|---|---|
| 面板 | 1.58" AMOLED，228 × 460，按对角线推算 **324.9 PPI**，显示区约 **17.8 × 36.0 mm**（以供应商规格书的有效显示区为准） |
| 驱动 | CO5300，QSPI（面板另支持 MIPI，S3 无 DSI，不用） |
| 圆角半径 | **16 px**（从产品图量得，待规格书确认） |
| 状态条 | y 0–25（26 px） |
| 转子窗口 | **y 90–336**（只在中间转；上下为纯黑文字区） |
| 文字安全内缩 | 左右 20 px（INSET） |

### 2.1 区域

```
y   0– 25   状态条：模式徽标 | 旋向 ↻/↺ | 到位 | 电量
转速在上、扭矩在下；扭矩是主信息，转速只占一行（v1.4）。

y  26– 89   纯黑 · 转速行（次）
            70   基线：转速数字 32px + rpm（16px）…… 右侧「上限 900」（15px）
                 不写"转速"二字（rpm 已说明）；棘轮为「分度 N 格」
y  90–336   转子窗口（上下各 12 px 渐隐到黑）
y 289–323   弧面槽格带 = 扭矩进度（中心 y=306，高 34），在窗口下部、扭矩正上方
y 337–459   纯黑 · 扭矩块（主）
           372   标签行（紧贴数字上方，间距约 20px）：左「扭矩 · 拧紧 / 松出」（18px，方向字用模式色，松出白）
                         右「上限 3.00 / 峰值 x.xx / 满 3.00」（16px）
           442   扭矩数字 + N·m（22px）。数字按 8.88 + 单位自动适配宽度（TURBO 前倾 + 辉光）
```

### 2.2 排版规则

- **中文最小 15 px**，标签 18 px
- **汉字字距 = 字号 × 12%**（只加在汉字段上，数字和英文不加；段尾字距去掉以便右对齐贴边）
- **数字后面必须跟单位**（扭矩 N·m、转速 rpm、分度 格）
- 数字一律**等宽**（逐字摆，每位同宽），跳数不左右抖
- **单位放在固定列**：按"最宽可能值"预留（扭矩 `8.88`，转速按上限位数），单位与数字间距 ≥ 6 px；放不下时整体缩小字号，绝不压缩间距
- 不使用"斜杠 + 上限"写法；上限写在标签行右侧

## 3. 转子（主体动画）

### 3.1 相机

转子轴竖直、与屏幕平行，相机在玻璃处正对转子。

| 参数 | 值 | 说明 |
|---|---|---|
| R | 110 | 转子半径（世界单位） |
| D | 164.3 | 相机到轴心距离 |
| F | 134.14（= 70.6 × 1.9） | 焦距；中心处 1 世界单位 = 1.30 px |
| 轮廓 | ±120.9 px | 略超出屏幕半宽 114 → 转子铺满，两侧接近掠射 |
| 边缘深度比 | 1.67 | 边缘比中心远 67% |

屏幕列 x → 光线 t = (x + 0.5 − 114)/F，与圆柱求交得表面角 a 与距离 s。

### 3.2 表面

| 参数 | 值 |
|---|---|
| 槽数 | 12（槽距 30°） |
| 槽口占比 SF | 0.24 |
| 斜槽 SKEW | 0.0022 rad / 世界单位（屏幕中心斜率 dx/dy ≈ −0.24） |
| 铜线横纹周期 | 1.4 世界单位（中心约 3.6 px） |
| 铜色 | (206, 112, 58) |

表面相位：`p = frac((a − θ + SKEW · wy) / 槽距)`，其中 `wy = sy · s / F`，`sy = y + 0.5 − CY`，CY = 243。

- 槽内（p < SF）：深色槽壁，受光侧略亮；槽底随负载透出模式色（强度 0.30 × load）
- 齿面：横纹 1.0 / 0.84 交替（v1.0 为 0.66，过晃），弧顶 0.86 + 0.14·sin
- 槽边：受光侧 1.6 px 亮唇（+70/+46/+28），背光侧压暗 35%
- 负载发热：齿面亮度 × (0.85 + 0.30 × load)

### 3.3 光照与深度

| 项 | 公式 |
|---|---|
| 漫反射 | 0.20 + 0.80 · max(0, cos(a + 0.32))^0.85 |
| 高光 | max(0, cos(a + 0.12))^22 × 0.18 |
| 远处衰减 | 1 − 0.40 · depth |
| 景深虚化 | depth × 6 px（depth = (s − Z0)/(Z_edge − Z0)） |

### 3.4 转动

> v1.1：v1.0 线性不封顶，每帧 0.7–1.35 槽距 → 频闪/倒转，**晃眼**。
> v1.2：v1.1 的 0.25 封顶 + 曝光拖影仍然**有残影、发晕**。拖影本质是多张错位画面叠加，看起来就是重影；整屏斜纹在动是发晕的主因。改为：转子只占中间窗口、再降速、取消拖影。

- **显示角速度是"示意"，不是真实转速**（真实转速由数字读出）。按每帧位移定义，单位"槽距/帧"（以 60 fps 标定）：
  `step = min(MAX_STEP, MAX_STEP · (rpm / 900)^0.6 · SPEED)`，MAX_STEP = **0.12**（中心约 3.5 px/帧，眼睛能平滑跟随），SPEED 默认 1.0
  - 精密 200 rpm ≈ 0.05 · 标准 450 rpm ≈ 0.08 · TURBO 900 rpm = 0.12
  - 其他帧率按时间换算（`step × 60 × dt`），但**任何帧率下每帧都不超过 MAX_STEP**
- 硬规则：**每帧位移 < 0.5 槽距**，否则必然频闪。棘轮驱动行程同样受此约束（见 §4.1）
- **不做运动模糊 / 拖影**（v1.2 取消）：每帧单次清晰采样。景深虚化保留（它是静态的，不产生残影）
- 景深按列选档（见 FIRMWARE_GUIDE §4），运动模糊档位恒为 0
- **减少动态**（设置项，建议默认跟随系统）：MAX_STEP 降到 0.05，关闭 TURBO 呼吸

### 3.5 窗口遮罩

在渲染通道内完成：窗口外不渲染（直接黑，省算力也省 AMOLED 功耗），窗口上下各 12 px 线性渐隐。

### 3.6 窗口与玻璃

两侧窄暗边（机壳厚度）、顶部内阴影、一道静止的斜向玻璃反光（alpha ≤ 0.06）。这些是画面中唯一静止的元素，承担旋转参照。

## 4. 模式

| 模式 | 颜色 | 目标扭矩 | 上限 | 转速 / 上限 | 运动 |
|---|---|---|---|---|---|
| 精密 | `#38BDFF` 冰蓝 | 0.35 | 1.00 | 200 / 300 | 连续 |
| 标准 | `#F28E4A` 铜 | 1.20 | 3.00 | 450 / 900 | 连续 |
| 棘轮 | `#4BE08A` 绿 | 2.40 | 3.00 | — | 往复（§4.1） |
| TURBO | `#FF3B7A` 品红 | 3.00 | 3.00 | 900 / 900 | 连续 + §4.2 |

- 模式色出现在：状态条徽标、槽格、槽底光、旋向标签
- 背景永远是铜，所以模式色避开橙 / 琥珀色相（标准模式例外：用更亮更饱和的铜，靠灰底托区分）
- 每个模式记住自己的扭矩设定
- 切换模式时颜色 0.7 s 缓动

### 4.1 棘轮运动

| 阶段 | 时长 | 行为 |
|---|---|---|
| 驱动行程 | 0.42 s | 转过 **1.5 个槽距**，smoothstep，无过冲：峰值约 0.09 槽距/帧 |
| 回程 | 0.30 s | 转子**完全静止**（v1.4.3 去掉反向顶动——看起来是抖）；在 0.06 / 0.135 / 0.21 s 各"咔"一次，只体现为亮格同步微亮（+0.15） |

1.5 而不是 1 个槽距：槽纹每个槽距重复，整槽距跳动在画面上等于没动。读数显示"格"（驱动次数）而不是 rpm。

### 4.2 TURBO

- **转子本体发红**：热度 h = 0.30 + 0.45·load；r × (1 + 0.10h)，g × (1 − 0.30h)，b × (1 − 0.22h)；槽缝透出余烬光 0.28 × load
- **扭矩数字**：同主扭矩尺寸、前倾（剪切 −0.12）（水平剪切 −0.16）、模式色辉光（6 + 16·load）、接近满扭矩时数字由白转暖；下方一道速度线随负载拉长
- 标签行右侧：模式色加粗「满扭矩 3.00」
- 槽格光晕随负载缓慢呼吸（1 + 0.12·load·sin(5t)，< 1 Hz；v1.0 为 0.45·sin(14t)，过闪）

## 5. 弧面槽格（能量条）

### 5.1 几何

画在与转子同轴、**不转动**的套筒上，与转子同一渲染通道，共享投影、衰减与景深。

| 参数 | 值 |
|---|---|
| 格数 | 15 |
| 格宽占比 | 0.62 |
| 弧面角 | ±0.60 rad |
| 高度 | 34 px，**全宽等高**（不随深度变矮——弧度不大时变矮反而显假） |
| 中心线 | y = 306，不下弯 |
| 斜度 | 与转子槽同一 SKEW，世界坐标下平行 |

### 5.2 配色（风格 A，默认）

| 层 | 规则 |
|---|---|
| 底托 | 条带区转子亮度 × 0.45，并去色 50%（不压黑，纹理保留） |
| 空格 | 底托 × 0.60（暗槽，不是黑洞） |
| 亮格 | 模式色 × (0.70 + 0.30·t)，t = 沿旋向的进度位置；t > 0.8 混白 35% |
| 受光唇 | 格起始边 1.3 px；窄格按格宽衰减，避免两侧被染白 |
| 光晕 | 指数衰减半径 2.6 px，强度 0.38 |

风格 C（可选）：亮格为模式色暗饱和 → 近白的发光渐变，光晕 0.55。

### 5.3 行为（按旋向）

| 事件 | 表现 |
|---|---|
| 拧紧 | **从左往右**填，满格 = 目标扭矩 |
| 松出 | **从右往左**填，满格 = 扭矩上限 |
| 扫光 | v1.2 取消 |
| 到位 | 一道白光沿旋向从起点冲到终点（0.35 s），整排转白 |
| 到位后松手 | 保持满格 0.30 s → 沿旋向逐格泄能（每格错开 0.035 s，各淡出 0.40 s）；泄完保持熄灭直到下次按下 |
| 扭矩读数 | 到位后松手保持 1.1 s 再回落 |
| 松出峰值 | 峰值位置一个**空心白框**（不填亮）；标签行右侧显示「峰值 x.xx」；松手 4 s 后消失 |
| 通用 | 格子变暗速率 ≤ 2.2 / s，任何情况不瞬间熄灭 |
| 棘轮"咔" | 亮格同步微亮（+0.15） |

方向的含义：填充方向与转子表面在屏幕上的移动方向一致，能量条"顺着转动"走。

## 6. 交互（沿用，未变）

单输入：横置滚轮 + 轮子本身是按键。

| 场景 | 滚动 | 短按 | 双击 | 长按 |
|---|---|---|---|---|
| 主界面 | 调扭矩 ±0.05 | 进菜单 | 换模式 | 锁屏 |
| 菜单 | 移光标 | 进入 / 编辑 | — | 返回 |
| 编辑 | 改值 | 保存 | — | 放弃（回滚） |
| 确认条 | 切换 | 执行 | — | 取消 |

短按永远前进，长按永远后退。防误触：滚动即取消长按计时；长按吞掉待定短按；运行中屏蔽短按；危险操作默认停在「取消」。菜单只到三级。

## 7. 帧率

| 平台 | 目标 |
|---|---|
| ESP32-S3 | **锁 30 fps**（TE 每两次 vsync 推一帧），60 为加分项 |
| ESP32-S31 | 目标 60 fps（320 MHz + SIMD） |

- 用 TE 同步时帧率只能是面板刷新（多为 60 Hz）的整除档：60 / 30 / 20
- 高于面板刷新的帧率在真机上看不到；原型里 72–144 档仅用于观感评估
- **原型默认"跟随显示器"**：每次显示器刷新推进一帧。选"真机 60"在 144 Hz 显示器上会 2/3 次刷新交替停留（144/60 不整除），画面发顿、有重影——这是浏览器演示的问题，真机按 TE 匀速出帧不会出现。评估观感请用跟随显示器，或把显示器设成 60/120 Hz
- 帧率不变式：所有动画按秒定义（本文全部时长均为秒），不按帧

## 8. 验收

1. 实测帧率达到 §7 目标，合成与推屏分开计时
2. 转子两侧可见压缩、变暗、虚化；中心锐利
3. 拧紧左→右、松出右→左；到位冲击波与泄能方向一致
4. 棘轮可见"推—咔咔咔"往复，静止时落点交错
5. TURBO 转子明显偏红但仍可辨为铜；扭矩数字放大前倾
6. 任何时候数字与单位不重叠；跳数不抖
7. 松手后槽格不瞬间熄灭；泄完不被重新点亮
8. 圆角区域无文字被裁切
