# SPEC —— 120×240 AMOLED 螺丝刀界面固件

版本 0.1 · 状态：待硬件验证

---

## 0. 一句话

一把精密电动螺丝刀的机身界面。主屏是一根**满屏纵向螺纹动画**，随电机转动；
输入只有**一个横置滚轮，轮子本身是按键**；菜单只到三级。

---

## 1. 硬件基线

| 项 | 值 | 来源 |
|---|---|---|
| MCU | ESP32-S3 | 已定 |
| 面板 | 0.95" AMOLED Bar，120×240 | 已定 |
| 驱动 IC | SH8501A | 已定 |
| 接口 | 4 线 SPI（GND/VCC/SCL/SDA/RES/DC/CS） | 模块实物 |
| SPI 写时钟上限 | 50 MHz（twc4 min 20ns） | 手册 2.3 |
| SPI 读时钟上限 | 10 MHz（trc4 min 100ns） | 手册 2.3 |
| 垂直滚动 | **不支持**（命令表无 33h/37h） | 手册 5.1 |
| TE | IC 有（35h/44h），**模块未引出** | 手册 3.1 + 实物 |
| QSPI | IC 支持（IM[2:0]=010），当前模块用不上 | 手册 4.1/4.8 |

**由此推出的硬约束**

- 动画必须靠像素传输实现，不能指望硬件滚动
- 帧预算按 50MHz 算，RGB565 全屏 57.6KB ≈ 9.2ms
- 运行时禁止读寄存器
- 满屏动画会撕裂，除非改板引出 TE

---

## 2. 屏幕分区

```
行 0   .. 13    状态条    14px   模式徽标 | 转速 | 电量
行 14  .. 195   动画区   182px   螺纹，满宽无边距
行 196 .. 239   压条      44px   扭矩大数字（渐变叠加在动画之上）
```

- 状态条**不放时钟**——工具上时间无用，电量才是会瞟的
- **底部提示条已取消**。语法一周成肌肉记忆，之后每天白占 6% 面积
- 动画区底部 12 行向下渐隐，让螺纹沉进压条，不是被硬切

## 3. 螺纹几何与光照

### 3.1 几何（改任意一项都要同步改贴图导出器）

| 参数 | 值 | 约束 |
|---|---|---|
| 牙距 pitch | 17 px | = 贴图高度 = 动画周期 |
| 线宽 wire | 14 px | **wire/pitch ≈ 0.85 才是螺纹；低于 0.5 会变成弹簧** |
| 振幅 amp | 46 px | 等径，侧面轮廓必须是长方形 |
| 透视深度 depth | 4.5 px | 越小越像实心杆 |
| 描边 | wire + 2 | 近黑，略带基色，避免死黑割裂 |

### 3.2 调色板（8 槽，从单一基色推导）

| 槽 | 用途 | 系数 |
|---|---|---|
| 0 | 背景黑 | 0.00 |
| 1 | 描边 | 0.06 |
| 2 | 芯轴暗部 | 0.20 |
| 3 | 背面圈 | 0.34 |
| 4 | 牙谷遮蔽 | 0.16 |
| 5 | 牙面暗档 | 0.42 |
| 6 | 牙面中档 | 0.72 |
| 7 | 牙峰 | 向白 +20% |

- **牙谷遮蔽是体积感的主要来源**，比高光重要。浅遮蔽在 16 位色暗部会被整段量化掉
- 牙谷遮蔽绘制：宽 0.62×wire，偏移 (0.6, 0.30×wire)，alpha 0.95
- 右缘冷反光：4px 宽 `#C8F0FF` @0.85，screen 混合。**窄而强**——宽而弱在低色深下变脏色带
- **不要**每圈一条白高光线，那是"塑料管"的成因
- 抖动（4×4 bayer 13%）只在 RGB565 路线用；4bpp 调色板路线下会变噪点

### 3.3 三个模式

| 模式 | 基色 | 默认扭矩 | 默认转速 | 动画行为 |
|---|---|---|---|---|
| 精密 | `#2FA8FF` | 0.35 N·m | 200 rpm | 连续旋转 |
| 标准 | `#FF8A2B` | 1.20 N·m | 450 rpm | 连续旋转 |
| 棘轮 | `#3ED66A` | 2.40 N·m | — | **一格一牙咬合，0.18s 一次** |

- 切换：颜色 0.7s 缓动插值；连续模式给转速冲量，棘轮模式改为六下减速咬合
- **每个模式记住自己的扭矩设定**
- 棘轮模式下转速读数换成**齿数**，松手归零

### 3.4 运动

```
步进(px/帧) = pitch × rpm / 3600        @60fps
```

- **Nyquist 上限 = pitch/2 = 8.5 px/帧 ≈ 1800rpm**，超过螺纹看起来倒转
- 实现必须把步进钳制在 0.45×pitch 以内
- 步进只能取整行，用小数累加器攒够整数再走
- 待机时保留 ~20rpm 的慢漂移，屏幕才是活的；锁屏时停

## 4. 排版

- **中文最小 12px**。8px 汉字在 120px 宽屏上只有 5×5 有效像素，糊成一团灰
- 扭矩数字 30~32px，等宽粗体，字距收紧
- 次要信息（实时扭矩、计数、操作提示）一律下放到菜单
- RGB565 路线所有颜色预先对齐格点：`(r&0xF8)|(r>>5)`

## 5. 交互

### 5.1 输入

一个横置滚轮（正交编码器）+ 轮子本身作为按键。没有第二个按钮。

### 5.2 手势语法（全局统一，**不能有例外**）

| 场景 | 滚动 | 短按 | 双击 | 长按 |
|---|---|---|---|---|
| 主界面 | 调扭矩 (±0.05) | 进菜单 | 换模式 | 锁屏 / 解锁 |
| 菜单浏览 | 移光标 | 进入 / 编辑 | — | 返回上级 |
| 编辑 | 改数值 | 保存 | — | **放弃改动**（回滚到进入前的值） |
| 确认条 | 切换选项 | 执行 | — | 取消 |

**原则：短按永远前进，长按永远后退。** 单键设备上只要有一处例外，
用户就得靠记忆而不是直觉。

### 5.3 防误触（必须实现）

- 一旦检测到滚动，取消当前长按计时（拧螺丝时压住轮子顺手转不该触发返回）
- 长按触发后吞掉待定的短按
- 电机运行中屏蔽短按
- 危险操作（恢复出厂）默认停在「取消」，必须主动转过去才选得到「确认」
- 进入编辑态时备份原值，长按能真正回滚

### 5.4 双击的代价

主界面短按需等 260ms 双击窗口。菜单里没有双击语义，可以在上层立即处理短按。

### 5.5 菜单结构（只到三级）

```
设置
├ 转速上限   num  100~900 step 50 rpm
├ 打砸反射   enum 关/轻/标准/强
├ 握力灵敏   num  1~10
├ 旋向       enum 正转/反转
└ 系统 ▸
  ├ 扭矩校准  read
  ├ 扭矩单位  enum N·m / kgf·cm / lbf·in
  ├ 恢复出厂  danger（走确认条）
  └ 关于      read
```

菜单行高 24px，一屏 8 行。

## 6. 渲染架构

### 6.1 核心事实

螺旋线在 y 方向严格周期：t 每增加 2π，x 回到原值、y 前进一个牙距。
**整屏只是一张 17×120 的贴图在纵向重复。**

### 6.2 数据

- 贴图以**调色板索引**存（每像素 1 字节，值 0~7），17×120 = 2040 字节
- 三个模式共用同一张贴图，换色只重算 8 个颜色再展开
- 展开后 `tile565[17][120]` = 4KB SRAM
- 动画区帧缓冲 120×182×2 = 43.7KB，必须 `MALLOC_CAP_DMA|MALLOC_CAP_INTERNAL`

### 6.3 每帧

1. 对每行 y：`memcpy(fb + y*120, tile565[(y+off)%17], 240)`
2. 底部 12 行移位衰减做渐隐
3. 等上一帧 DMA 完成
4. `CASET + PASET + RAMWR` 推 182 行

状态条和压条**只在内容变化时**刷（脏矩形，5~10Hz 足够）。

### 6.4 贴图生成

PC 端渲染，抗锯齿/遮蔽/光照/抖动全部预先烘进去。
**渲染 5 个连续周期，取正中间那个**——直接截一段的话 round cap 被切断，接缝对不上。

## 7. 性能

目标 60fps（16.7ms/帧）@50MHz SPI

| 项 | 预算 |
|---|---|
| 合成动画区 | ~0.3 ms CPU |
| 推屏 43.7KB | ~7.0 ms DMA |
| 数字脏矩形 | ~0.9 ms，按需 |
| 余量 | ~8 ms |

**不达标时的降级路径**：切 SPI 1-1-1 调色板模式（COLMOD 3Ah + COLSET 70h~7Fh + COLOPT 80h），
每字节两像素，数据量降到 1/4（14.4KB，2.3ms）。贴图本来就是索引存的，只需改推屏路径。
额外好处：**换模式只重写 COLSET 寄存器，几十字节，零像素传输**。

## 8. AMOLED 专项

- **防烧屏**：状态条和大数字位置固定。息屏超时 + 定期 1~2px 整体偏移 + `WRDISBV(51h)` 降亮度
- **AOD 待机**：`AODON(49h)` + `AOD_WRDISBV(4Ah)`，只留扭矩数字
- **黑色不耗电**：黑底设计正好；满屏亮螺纹是功耗大头，考虑只在运行时全亮

---

## 9. 验收标准

1. 主界面螺纹连续旋转，实测 ≥55fps（GPIO 翻转 + 逻辑分析仪，合成与推屏分开计时）
2. 三个模式切换，颜色 0.7s 平滑过渡，无跳变、无撕裂加剧
3. 棘轮模式一格一牙，咬合可辨，与连续旋转在视觉上明确不同
4. 滚轮一格对应一个刻度/一个条目，无跳两格
5. 长按 500ms 触发返回；按住期间转动不触发返回
6. 编辑态长按能回滚到进入前的值
7. 转速拉到上限时螺纹方向不反转
8. 12px 中文在真机上可读，8px 不做要求（已弃用）
